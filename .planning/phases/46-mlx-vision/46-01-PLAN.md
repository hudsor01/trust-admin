<task type="auto">
  <name>Task 2: Create inventory analysis API route with Zod validation</name>
  <files>src/app/api/inventory/analyze/route.ts, src/lib/inventory-analysis.ts</files>
  <action>
1. Install openai package if not present: `bun add openai`

2. Create `src/lib/inventory-analysis.ts`:
   - Define Zod schema for analysis response (InventoryAnalysisSchema)
   - Define AI category → DB enum mapping function
   - AI categories: furniture, electronics, appliances, artwork, jewelry, collectibles, clothing, tools, sports_equipment, musical_instruments, kitchenware, decor, books_media, office_equipment, outdoor, vehicles, other
   - Map to DB categories: FURNITURE, ELECTRONICS, ART (for artwork/decor), JEWELRY, COLLECTIBLES, OTHER (catch-all)
   - Export INVENTORY_ANALYSIS_PROMPT constant
   - Export analyzeInventoryImage function (takes base64, mimeType)

3. Create `src/app/api/inventory/analyze/route.ts`:
   - POST endpoint accepting { imageBase64: string, mimeType: string }
   - Create OpenAI client pointing to OLLAMA_URL/v1
   - Call Qwen3-VL:8b with vision prompt
   - Parse and validate response with Zod
   - Map AI category to DB enum
   - Return typed response or error

**Prompt engineering (from research):**
- Use "ONLY valid JSON, no other text" instruction
- Set temperature: 0.1 for consistent output
- max_tokens: 500
- Include exact JSON structure in prompt

**Model customization for accuracy:**
- Create a domain-specific system prompt that establishes the model as a "trust inventory specialist"
- Include context about trust property valuation (fair market value, not retail/replacement)
- Provide category definitions with examples to reduce misclassification
- Add instruction to flag uncertainty (e.g., "confidence": "low") rather than hallucinate values
- Consider Ollama Modelfile for persistent system prompt customization if results need tuning

**Error handling:**
- JSON parse failure → 422 with raw content for debugging
- Ollama connection failure → 503 Service Unavailable
- Zod validation failure → return partial with warnings
