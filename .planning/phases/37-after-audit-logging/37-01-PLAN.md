# Phase 37 Plan 01: after() for Audit Logging

<objective>
Convert auth event logging to use Next.js `after()` API so audit log writes don't block response delivery. Fire-and-forget pattern - errors logged but responses never wait for audit writes.
</objective>

<execution_context>
**Load for implementation:**

- @.planning/phases/37-after-audit-logging/37-CONTEXT.md (user vision)
- @src/lib/auth-events.ts (migration target)
</execution_context>

<context>
**What exists:**
- `src/lib/auth-events.ts` - Contains `recordAuthEvent()` and `recordSignIn()` functions
- Current implementation uses synchronous `await db.insert(activityLog)` blocking the response
- Already has try/catch error handling that logs failures without throwing

**What changes:**
- Wrap the `db.insert()` call inside `after()` callback from `next/server`
- Response returns immediately, audit log write happens in background
- Error handling stays the same (fire-and-forget)

**From research:**
- `after()` is from `next/server`, works in Route Handlers and Server Actions
- Pattern: `after(async () => { try { await db.insert() } catch { logger.error() } })`
- No return value from after() callbacks - fire-and-forget only
</context>

## Task 1: Update recordAuthEvent() to use after()

**Files:** `src/lib/auth-events.ts`

**What to do:**
1. Add import: `import { after } from 'next/server'`
2. Wrap the `db.insert(activityLog).values({...})` call inside `after(async () => {...})`
3. Keep the existing try/catch for error handling inside the after() callback
4. Remove `await` from the outer function since after() is fire-and-forget
5. Function return type stays `Promise<void>` but now resolves immediately

**Before:**
```typescript
export async function recordAuthEvent(...): Promise<void> {
  try {
    await db.insert(activityLog).values({...})
  } catch (error) {
    logger.db.error('Failed to record auth event', { action, error })
  }
}
```

**After:**
```typescript
export function recordAuthEvent(...): void {
  after(async () => {
    try {
      await db.insert(activityLog).values({...})
    } catch (error) {
      logger.db.error('Failed to record auth event', { action, error })
    }
  })
}
```

**Commit:** `feat(37-01): convert recordAuthEvent to use after() for non-blocking audit`
