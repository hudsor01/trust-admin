  <name>Task 2: Add PaymentPreview component with real-time calculation</name>
  <files>src/app/(admin)/liabilities/page.tsx</files>
  <action>
Create a PaymentPreview component that shows "Estimated monthly payment: $X" as the user types loan terms.

Implementation:

1. Import calculation utilities and React hooks at top of file:
```tsx
import { useDeferredValue, useMemo } from 'react'
import { calculateMonthlyPayment, estimatePayoffDate } from '@/lib/amortization'
```

2. Create PaymentPreview component inside the file (not a separate file - keeps context together):
```tsx
function PaymentPreview({ formInstance }: { formInstance: typeof liabilityFormInstance }) {
  // Subscribe to relevant form values
  const principal = formInstance.useStore(s => s.values.originalAmount)
  const rate = formInstance.useStore(s => s.values.interestRate)
  const term = formInstance.useStore(s => s.values.loanTermMonths)
  const liabilityType = formInstance.useStore(s => s.values.liabilityType)

  // Don't show for revolving credit (no fixed term)
  if (isRevolvingType(liabilityType)) return null

  // Defer inputs for smooth typing
  const deferredPrincipal = useDeferredValue(principal)
  const deferredRate = useDeferredValue(rate)
  const deferredTerm = useDeferredValue(term)

  // Calculate payment only when deferred values settle
  const calculated = useMemo(() => {
    if (!deferredPrincipal || !deferredRate || !deferredTerm) return null

    const p = parseFloat(deferredPrincipal)
    const r = parseFloat(deferredRate)
    const t = parseInt(deferredTerm, 10)

    if (isNaN(p) || isNaN(r) || isNaN(t) || p <= 0 || r < 0 || t <= 0) return null

    const rateDecimal = (r / 100).toString()
    const payment = calculateMonthlyPayment(deferredPrincipal, rateDecimal, t)
    const payoffDate = estimatePayoffDate(deferredPrincipal, rateDecimal, payment)

    return { payment, payoffDate }
  }, [deferredPrincipal, deferredRate, deferredTerm])

  if (!calculated?.payment) return null

  return (
    <div className="rounded-lg bg-muted/50 p-3 mt-4 transition-all duration-200">
      <div className="text-sm text-muted-foreground">
        Estimated Monthly Payment (P&I)
      </div>
      <div className="text-lg font-semibold">
        {formatCurrency(calculated.payment)}
      </div>
      {calculated.payoffDate && (
        <div className="text-xs text-muted-foreground mt-1">
          Payoff date: {new Date(calculated.payoffDate).toLocaleDateString()}
        </div>
      )}
    </div>
  )
}
```

3. Insert PaymentPreview inside the loan term fields section, after the escrow field (~line 958), still inside the `hasLoanTermFields` conditional area.

**What to avoid and WHY:**
- Don't calculate on every keystroke without useDeferredValue - causes lag
- Don't use setTimeout/useDebounce - useDeferredValue is smarter (interruptible)
- Don't skip the null checks - calculateMonthlyPayment returns null for impossible calculations
