    1. Has same signature as `getAll()` for filterValue
    2. Always returns `Select[]` (never `PaginatedResult<Select>`)
    3. Internally calls `getAll()` without pagination
    4. Handles the union return type: `Array.isArray(result) ? result : result.data`

    This eliminates 20+ places in the codebase where callers need:
    ```typescript
    const result = await crud.getAll(entityId)
    return Array.isArray(result) ? result : result.data
    ```

    Instead they can use:
    ```typescript
    return crud.getAllArray(entityId)
    ```

    Also update the `CrudOperations` type to include the new method.
  </action>
