**Current pattern (manual):**
- Separate state for `showForm`, `editingEntry`, `formData`

- Manual close/reset logic

**Target pattern (Phase 4 components):**
- Single `useResourceForm` hook for state management
- Form fields as children of ResourceDialog
- Automatic dialog open/close, form reset, editing state management
- Consistent UX across all pages

**Phase 5 established pattern:**
- Track editing ID separately from form data
- Custom edit handlers transform entity data → form data
- Dialog handlers passed to ResourceDialog component

<action>
1. Import useResourceForm from @/hooks
2. Replace manual state (showForm, editingEntry, formData, setFormData) with useResourceForm hook:
   ```typescript
   const { isOpen: isDialogOpen, close: closeDialog, form: entryForm,
           setForm: setEntryForm, handleEdit: handleEditEntry,
           handleAdd: handleAddEntry, handleSave: handleSaveEntry,
           isSubmitting: isEntrySaving } = useResourceForm<AccountingFormData>({
     initialData: defaultFormData,
     onSubmit: async (data) => {
       if (!selectedEntity) return
       const payload = {
         entityId: selectedEntity,
         accountingDate: data.accountingDate,
         entryType: data.entryType,
         incomeType: data.entryType === "INCOME" ? data.incomeType : null,
         expenseType: data.entryType === "EXPENSE" ? data.expenseType : null,
         amount: data.amount,
         description: data.description || null,
         isPrincipal: data.isPrincipal,
         taxDeductible: data.taxDeductible,
         referenceNumber: data.referenceNumber || null,
         sourceAssetType: data.sourceAssetType || null,
         sourceAssetId: data.sourceAssetId || null,
       }
       if (isEditing) {
         await updateEntry(editingId, payload)
       } else {
         await createEntry(payload)
       }
     },
   })
   ```

4. Delete: manual `resetForm`, `openEditForm`, `handleSave` functions
5. Update "Add Entry" button onClick: use hook's `handleAdd`
6. Update edit button (line ~1029): `openEditForm(entry)` → use hook's `handleEdit(entry)`
