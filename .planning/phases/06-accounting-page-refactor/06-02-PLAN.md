Accounting.tsx has manual Table component (lines 940-1045) with 7 columns, inline editing, and custom rendering for badges/tooltips. The table is wrapped in Tabs for filtering (All/Income/Expense).

**Current pattern (manual):**
- Manual Table with TableHeader, TableBody, TableRow, TableCell
- Custom rendering for each cell type (badges, dates, currencies, flags)
- Inline EditableTextCell and EditableCurrencyCell components
- Action buttons (Edit, Delete) with tooltips
- ~105 lines of table markup

**Target pattern (DataTable):**
- DataTable component with declarative column configuration
- Column render functions handle custom display logic
- Automatic loading, empty states
- Sorting built-in (optional for this table)
- ~25 lines of column config + DataTable invocation

**Accounting table columns:**
1. Date - formatDate(accountingDate)
2. Type - Badge (INCOME/EXPENSE)
3. Category - Label from INCOME_TYPES or EXPENSE_TYPES
4. Description - EditableTextCell with inline editing
5. Amount - EditableCurrencyCell with color coding
6. Flags - Badges for Principal (P) and Tax Deductible (D) with tooltips
7. Actions - Edit/Delete buttons with tooltips

**Files to modify:**

       ),

           placeholder="Add description"
         />
       ),
     },
     {
       accessorKey: "amount",
       header: "Amount",
       cell: ({ row }) => (
         <div className={cn("text-right", row.original.entryType === "INCOME" ? "text-success" : "text-destructive")}>
           <EditableCurrencyCell
             value={row.original.amount}
             onSave={async (v) => updateEntry(row.original.id, { amount: v || "" })}
           />
         </div>
       ),

       header: "Flags",
       cell: ({ row }) => (
         <div className="flex gap-1">
           {row.original.isPrincipal && (

                 </TooltipTrigger>

               </Tooltip>
             </TooltipProvider>

                 </TooltipTrigger>
