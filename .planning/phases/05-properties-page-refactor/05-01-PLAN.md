Replace manual Homestead and Rental Property dialog forms with ResourceDialog component and useResourceForm hook to eliminate ~700 lines of duplicate dialog management code.

<context>
Properties.tsx currently has two large form dialogs (Homestead: lines 750-1083, Rental: lines 1086-1444) with manual state management. Phase 4 created ResourceDialog and useResourceForm to standardize this pattern.

**Current pattern (manual):**
- Separate state for `showHomesteadForm`, `editingHomestead`, `homesteadForm`
- Separate handlers: `handleAddHomestead`, `handleEditHomestead`, `handleSaveHomestead`
- Manual Dialog with Cancel/Save buttons in DialogFooter
- Same pattern duplicated for Rental Properties

**Target pattern (Phase 4 components):**
- Single `useResourceForm` hook per resource type
- Form fields as children of ResourceDialog
- Automatic dialog open/close, form reset, editing state management
- Consistent UX across all pages

**Files to modify:**
- `src/pages/Properties.tsx` - Replace both dialogs with ResourceDialog pattern

**Success criteria:**
- Both Homestead and Rental dialogs use ResourceDialog
- Both use useResourceForm for state management
- All form fields preserved (no functionality lost)
- File reduced by ~600+ lines
- TypeScript compiles without errors
</context>

<task id="1">
<files>src/pages/Properties.tsx</files>
<action>
Replace Homestead dialog state management with useResourceForm hook.

1. Import useResourceForm from @/hooks
2. Replace manual state (showHomesteadForm, editingHomestead, homesteadForm) with useResourceForm hook:
   ```typescript
   const { isOpen: isHomesteadOpen, close: closeHomestead, form: homesteadForm,
           setForm: setHomesteadForm, handleEdit: handleEditHomestead,
           handleAdd: handleAddHomestead, handleSave: handleSaveHomestead,
           isSubmitting: isHomesteadSubmitting } = useResourceForm<HomesteadFormData>({
     initialData: defaultHomesteadForm,
     onSubmit: async (data) => {
       if (!selectedEntity) return
       const payload = {
         entityId: selectedEntity,
         streetAddress: data.streetAddress,
         // ... (keep existing payload mapping from handleSaveHomestead)
       }
       if (isEditing) {
         await updateHomestead(editingId, payload)
       } else {
         await createHomestead(payload)
       }
     },
   })
   ```
3. Delete: `showHomesteadForm`, `editingHomestead` state variables
4. Delete: manual `handleAddHomestead`, `handleEditHomestead`, `handleSaveHomestead` functions (lines 241-361)
5. Update button onClick: `handleAddHomestead` → use hook's `handleAdd`
6. Update edit button: `handleEditHomestead(h)` → use hook's `handleEdit(h)`

Verify: Code compiles, no unused variables
</action>
