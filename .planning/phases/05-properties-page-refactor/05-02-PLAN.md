<context>
Properties.tsx Rental Properties tab currently uses manual Table component (lines 638-743) with inline editable cells. Phase 4 created DataTable component to standardize this pattern with column configuration.

**Current pattern (manual Table):**
```typescript
<Table>
  <TableHeader>
    <TableRow>
      <TableHead>Name</TableHead>
      {/* ... 7 more columns */}
    </TableRow>
  </TableHeader>
  <TableBody>
    {rentals.map((r) => (
      <TableRow key={r.id}>
        <TableCell>
          <EditableTextCell value={r.name} onSave={...} />
        </TableCell>
        {/* ... 7 more cells with inline editing */}
      </TableRow>
    ))}
  </TableBody>
</Table>
```

**Target pattern (DataTable):**
```typescript
const columns: ColumnDef<RentalProperty>[] = [
  {
    key: "name",
    header: "Name",
    sortable: true,
    render: (item) => <EditableTextCell value={item.name} onSave={...} />
  },
  // ... declarative column config
]

<DataTable
  data={rentals}
  columns={columns}
  onEdit={handleEditRental}
  onDelete={handleDeleteRental}
  isLoading={rentalsLoading}
/>
```

**Benefits:**
- Declarative column configuration (easier to modify)
- Built-in sorting support
- Consistent action buttons (Edit/Delete)
- Loading and empty states handled
- Reduces ~80 lines of table markup

**Files to modify:**
- `src/pages/Properties.tsx` - Replace rental properties table
</context>
