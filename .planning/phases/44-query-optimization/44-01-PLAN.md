  <name>Task 2: Add entityId filter to hemsRequest list</name>
  <files>src/server/trpc/routers/hemsRequest.ts</files>
  <action>
The hemsRequest CRUD already has `filterColumn: 'beneficiaryId'` set. For entityId filtering, we need a different approach since the entity relationship is through the beneficiary.

Option A (simple): Keep in-memory filter since entityId filtering is rare (most queries are by beneficiaryId)
Option B (optimal): Add dedicated query function

Given the HEMS table likely has <100 records at any time, Option A is acceptable. Add a comment explaining the tradeoff.

Update hemsRequest.ts:
```typescript
list: adminProcedure
    .input(...)
    .query(async ({ input }) => {
        const data = await hemsRequestCrud.getAllArray(input?.beneficiaryId)
        // Note: entityId filtering done in-memory as HEMS requests are typically <100 records
        // and entityId filter path is rare (most filtering is by beneficiaryId)
        if (input?.entityId) {
            return data.filter((r) => r.entityId === input.entityId)
        }
        return data
    }),
```

The comment documents the intentional tradeoff.
  </action>
