<objective>
Switch accounting page from downloading all 500 rows with client-side pagination to server-side paginated queries with entryType filtering.

Purpose: The accounting page currently fetches up to 500 rows via `trustAccounting.list` and relies on DataTable for client-side pagination. With growing data, this transfers increasing payloads and slows initial load. The existing `listPaginated` procedure already supports LIMIT/OFFSET -- it just needs an `entryType` filter parameter and the client needs to use it instead of `list`.

Output: Accounting page loads 50 rows per page, tabs filter server-side, tab badges show accurate totals.
</objective>
