<objective>
Replace client-side accounting aggregation with SQL SUM, clean up redundant queries and dead code in the dashboard.

Purpose: The dashboard currently fetches ALL trustAccounting rows (unbounded) to sum them client-side via `sumStrings()`. This scales linearly with data volume and transfers potentially thousands of rows to the browser. SQL SUM computes totals in constant time with zero row transfer. Additionally, `entity.byId` duplicates data already in the `entity.list` cache, and four `_total*` variables are computed but never consumed.

Output: Dashboard loads with SQL-computed totals, no unbounded row fetches, cleaned-up client component.
</objective>
