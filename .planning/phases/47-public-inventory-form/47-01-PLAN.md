# Phase 47 Plan 01: Public Inventory Form

## Objective

Create a public-facing inventory submission form at `/forms/inventory` where anyone can submit personal property items with optional photo upload and AI-assisted field population. Submissions go to a pending queue for admin review (Phase 48).

## Context

**Workflow:**
1. User navigates to `/forms/inventory` (public, no auth)
2. User fills form: item name, category, description, estimated value, condition
3. Optionally uploads 1-5 photos
4. If photos uploaded → calls `/api/inventory/analyze` → pre-fills fields
5. User reviews/adjusts AI suggestions
6. Submits → creates `pendingInventoryItem` record
7. Admin reviews in Phase 48 queue

**Data Flow:**
```
[Public Form] → [Photo Upload to local FS]
                      ↓
              [AI Analysis API]
                      ↓
[Form Fields Pre-populated] → [User Adjusts] → [Submit]
                                                  ↓
                                    [pendingInventoryItem table]
                                                  ↓
                                    [Admin Queue (Phase 48)]
```

**Schema Design:**
```typescript
// New table: pendingInventoryItem
{
  id: bigint,
  // Submission data
  name: text NOT NULL,
  category: PersonalPropertyCategory NOT NULL,
  description: text,
  estimatedValue: numeric(12,2),
  condition: ConditionEnum ('excellent'|'good'|'fair'|'poor'),
  // Photo references (local paths)
  photoPath1: text,
  photoPath2: text,
  photoPath3: text,
  photoPath4: text,
  photoPath5: text,
  // AI analysis metadata
  aiConfidence: text, // 'high'|'medium'|'low'|null
  aiSuggested: boolean, // true if AI pre-filled
  // Review workflow
  status: SubmissionStatus ('pending'|'approved'|'rejected'),
  reviewNotes: text,
  approvedAt: timestamp,
  approvedBy: bigint (FK to user),
  // Target entity (set by admin on approval)
  entityId: bigint (FK to entity, nullable until approved),
  // Tracking
  submitterName: text, // Optional contact info
  submitterEmail: text,
  submitterPhone: text,
  createdAt: timestamp,
  updatedAt: timestamp,
}
```

### Task 2: Photo Upload API

**Objective:** Create API endpoint to handle photo uploads to local filesystem

**Files to create:**
- `src/app/api/inventory/upload/route.ts` - POST endpoint for photo upload

**Implementation:**
1. Accept multipart/form-data with up to 5 images
2. Validate file types (jpeg, png, gif, webp)
3. Validate file sizes (max 10MB each)
4. Generate unique filenames with timestamp + UUID
5. Save to `public/uploads/inventory/` directory
6. Return array of file paths

**API Contract:**
```typescript

// Request: FormData with 'photos' field (multiple files)
// Response: { success: true, paths: string[] }
```
