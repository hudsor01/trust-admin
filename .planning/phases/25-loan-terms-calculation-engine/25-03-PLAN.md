**Current behavior:**
- User manually enters principalPortion and interestPortion
- If not provided, they're stored as null
- Payment amount is subtracted from currentBalance

**Target behavior:**
- If liability has interestRate AND user doesn't provide portions:
  - Auto-calculate using calculatePaymentSplit()
  - Store calculated portions in payment record
- If liability is revolving credit (isRevolvingCredit=true):
  - Skip amortization calculation (no fixed term)
- If user provides portions manually:
  - Use their values (override auto-calculation)

**Integration points:**
1. recordLiabilityPayment in db/queries.ts
2. recordPayment mutation in liability router (already calls recordLiabilityPayment)

getPayoffProjection: adminProcedure

  .query(async ({ input }) => {
    const liabilityRecord = await liabilityCrud.getById(input)

      liabilityRecord.currentBalance,
