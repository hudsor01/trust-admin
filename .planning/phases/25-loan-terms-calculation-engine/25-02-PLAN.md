**Amortization formulas:**

1. **Monthly payment from loan terms:**
   M = P * [r(1+r)^n] / [(1+r)^n - 1]
   - P = principal, r = monthly rate (annual/12), n = term in months

2. **Interest portion of payment:**
   Interest = Current Balance * (Annual Rate / 12)
   Principal = Payment Amount - Interest - Escrow

3. **Payoff date estimation:**
   Months to payoff = -log(1 - (Balance * r / Payment)) / log(1 + r)
   - Only valid when Payment > Balance * r (otherwise never pays off)

4. **Current loan position:**
   Given original terms + current balance, calculate:
   - Payments made (estimated)
   - Payments remaining
   - Principal paid to date
   - Interest paid to date

**Edge cases to test:**
- Zero interest rate (divide by zero protection)
- Revolving credit (no fixed term)
- Extra payments (payment > scheduled)
- Insufficient payment (payment < interest due)
- Paid off (balance = 0)

**calculatePaymentSplit(currentBalance, annualRate, paymentAmount, escrowAmount?)**
- Input: balance "250000.00", rate "0.065" (6.5%), payment "1800.00", escrow "350.00"
- Output: { principal: "589.17", interest: "1354.17", escrow: "350.00", newBalance: "249410.83" }
- Edge: Zero rate → all payment goes to principal (minus escrow)
- Edge: Payment < interest → principal is negative (balance increases)

**estimatePayoffDate(balance, annualRate, monthlyPayment, escrowMonthly?, startDate?)**
- Input: balance "250000.00", rate "0.065", payment "1800.00", escrow "350.00"
- Output: { monthsRemaining: 287, payoffDate: "2050-01-15", totalInterest: "165400.00" }
- Edge: Payment <= interest due → returns null (never pays off)
- Edge: Zero balance → returns { monthsRemaining: 0, payoffDate: now, totalInterest: "0" }

**calculateMonthlyPayment(principal, annualRate, termMonths)**
- Input: principal "250000.00", rate "0.065", term 360
- Output: "1580.17" (standard 30yr mortgage payment)
- Edge: Zero rate → principal / termMonths
- Edge: Zero term → returns null

**getCurrentLoanPosition(originalAmount, annualRate, termMonths, startDate, currentBalance)**

- Edge: Paid ahead (balance lower than expected) → adjusts remaining payments
