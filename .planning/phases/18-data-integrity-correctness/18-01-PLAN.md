   ```
   !data.principalPortion && !data.interestPortion

   to:
   ```
   data.principalPortion == null && data.interestPortion == null

   parseFloat(data.principalPortion || '0')

In db/queries.ts, refactor `recalculateBeneficiaryShares` (lines 1726-1733):
Replace the for-loop issuing N individual UPDATEs with a single bulk UPDATE using a VALUES join pattern:

```typescript
if (updates.length > 0) {
    // Build parameterized values for bulk update
    // Use postgres.js tagged template with dynamic SQL
    const valueRows = updates.map(u =>
        sql`(${u.id}::int, ${u.newShare}::text, ${now}::text)`
    )
    await tx`
        UPDATE beneficiary AS b
        SET "sharePercent" = v.share,
            "updatedAt" = v.ts::timestamptz
        FROM (VALUES ${sql.join(valueRows, sql`,`)}) AS v(id, share, ts)
        WHERE b.id = v.id
    `
}
```

Note: postgres.js `sql` helper is already imported in this file. If `sql.join` is not available, use the unsafe approach with application-controlled values (integer IDs and decimal strings from computation, not user input).
