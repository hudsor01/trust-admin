1. **Liability dialog** - Create/edit liabilities with manual state (showForm, editing, form)
2. **Payment dialog** - Record payments with manual state (showPaymentForm, payingLiability, paymentForm)

**Current pattern (manual):**
- Separate state for each dialog: showForm, showPaymentForm
- Separate editing state: editing, payingLiability
- Manual form data: form, paymentForm
- Manual handlers: resetForm, openEdit, handleSave, recordPayment

**Target pattern (Phase 4 components):**
- Single useResourceForm hook per dialog for state management
- Form fields as children of ResourceDialog
- Automatic dialog open/close, form reset, editing state management
- Consistent UX with Properties, Accounting, and all Phase 4+ pages

**Phase 6 established pattern:**
- Track editing ID separately from form data
- Custom edit handlers transform entity data → form data
- Dialog handlers passed to ResourceDialog component
- Payment recording as separate workflow (custom endpoint)

**Success criteria:**

1. Replace manual Payment dialog state (lines 163-166) with useResourceForm hook:
   ```typescript
   const [payingLiabilityId, setPayingLiabilityId] = useState<string | null>(null)

   const {
     isOpen: isPaymentOpen,
     close: closePayment,
     form: paymentFormData,
     setForm: setPaymentFormData,
     handleEdit: handleOpenPayment,
     handleSave: handleRecordPayment,
     isSubmitting: isRecordingPayment,
   } = useResourceForm<PaymentFormData>({
     initialData: defaultPaymentForm(),
     onSubmit: async (data) => {
       if (!payingLiabilityId) return

       const payload = {
         paymentDate: data.paymentDate,
         amount: parseFloat(data.amount) || 0,
         principalAmount: parseFloat(data.principalAmount) || null,
         interestAmount: parseFloat(data.interestAmount) || null,
         paymentMethod: data.paymentMethod as "CHECK" | "ACH" | "WIRE" | "CREDIT_CARD" | "CASH" | "OTHER",
         checkNumber: data.checkNumber || null,
         notes: data.notes || null,
       }

       await fetch(`/api/liabilities/${payingLiabilityId}/record-payment`, {
         method: "POST",
         headers: { "Content-Type": "application/json" },
         body: JSON.stringify(payload),
       })

       setPayingLiabilityId(null)
       fetchLiabilities(selectedEntity!)
     },
   })
   ```
