<context>
Accounts.tsx currently has 2 manual dialog forms and 2 manual tables in tabs:
- **Bank Account dialog** - Manual state (showBankForm, editingBank, bankForm)
- **Investment Account dialog** - Manual state (showInvestmentForm, editingInvestment, investmentForm)
- **Bank Accounts table** - Manual Table with 8 columns + inline editing
- **Investment Accounts table** - Manual Table with 8 columns + inline editing

**Current pattern (manual):**
- Separate state for each dialog
- Separate form data: bankForm, investmentForm
- Manual handlers: resetBankForm, resetInvestmentForm, etc.
- Manual Table components with ~120 lines each
- Tabs wrapper for switching between account types

**Target pattern (Phase 4 components):**
- Two useResourceForm hooks (one per account type)
- Two ResourceDialog components
- Two DataTable components (inside tabs)
- Automatic dialog open/close, form reset, editing state management
- Consistent UX with Properties, Accounting, Liabilities pages

**Files to modify:**
- `src/pages/Accounts.tsx` - Replace both dialogs and both tables

**Success criteria:**
- Both dialogs use ResourceDialog component
- State management uses useResourceForm hooks (2 instances)
- Both tables use DataTable component
- All form fields preserved (no functionality lost)
- Tabs structure preserved
- File reduced by ~300-350 lines
- TypeScript compiles without errors
</context>

<action>
1. Import useResourceForm from @/hooks/use-resource-form

4. Replace manual Bank dialog state (lines 133-134, 148) with useResourceForm hook:
   ```typescript
   const [editingBankId, setEditingBankId] = useState<string | null>(null)

   const {
     isOpen: isBankOpen,
     close: closeBankDialog,
     form: bankFormData,
     setForm: setBankFormData,
     handleEdit: handleEditBankForm,
     handleAdd: handleAddBank,
     handleSave: handleSaveBank,
     isSubmitting: isBankSaving,
     isEditing: isEditingBank,
   } = useResourceForm<BankFormData>({
     initialData: bankAccountFormDefaults(),
     onSubmit: async (data) => {
       if (!selectedEntity) return
       const payload = {
         entityId: selectedEntity,
         institution: data.institution,
         accountType: data.accountType,
         accountName: data.accountName,
         accountNumber: data.accountNumber || null,
         routingNumber: data.routingNumber || null,
         dodValue: parseFloat(data.dodValue) || null,
         dodValueDate: data.dodValueDate || null,
         status: data.status,
         transferStatus: data.transferStatus,
         notes: data.notes || null,
       }
       if (isEditingBank && editingBankId) {
         await fetch(`/api/bank-accounts/${editingBankId}`, {
           method: "PUT",
           headers: { "Content-Type": "application/json" },
           body: JSON.stringify(payload),
         })
       } else {
         await fetch("/api/bank-accounts", {
           method: "POST",
           headers: { "Content-Type": "application/json" },
           body: JSON.stringify(payload),
         })
       }
       setEditingBankId(null)
       fetchBankAccounts(selectedEntity)
     },
   })
   ```
5. Create custom edit handler:
   ```typescript
   const handleEditBank = (b: BankAccount) => {
     setEditingBankId(b.id)
     handleEditBankForm({

       accountName: b.accountName,
       accountNumber: b.accountNumber || "",
       routingNumber: b.routingNumber || "",
       dodValue: b.dodValue?.toString() || "",
       dodValueDate: toDateInput(b.dodValueDate) || null,
       status: b.status,
       transferStatus: b.transferStatus,
       notes: b.notes || "",
     })
   }
   ```
6. Delete: manual Bank state variables (showBankForm, editingBank, bankForm)
7. Delete: manual Bank handlers (resetBankForm, etc.)
8. Update "Add Bank Account" button onClick: use handleAddBank
9. Update edit button: use handleEditBank(account)

Verify: Code compiles, Bank dialog state uses hook
