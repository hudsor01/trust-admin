# Plan 01-01: Switch to Neon Serverless Driver

## Objective

Replace the `postgres` package with `@neondatabase/serverless` for optimized HTTP-based queries in serverless/edge environments while maintaining RLS support.

## Context

Currently using:
- `postgres` package (TCP connections)
- Direct connections to Neon

Benefits of serverless driver:
- Lower latency for simple queries (HTTP vs TCP)
- Better serverless cold start times
- Native WebSocket support for transactions
- Message pipelining optimization
