**Pattern to extract (repeated 6 times with slight variations):**
```typescript
const [editing, setEditing] = useState(false)
const [editValue, setEditValue] = useState(value || '')
const [saving, setSaving] = useState(false)

const handleSave = async () => {
    if (editValue === (value || '')) {
        setEditing(false)
        return
    }
    setSaving(true)
    try {
        await onSave(editValue || null)
        setEditing(false)
    } catch (e) {
        console.error('Save failed:', e)
    } finally {
        setSaving(false)
    }
}
```

**Components using this pattern:**
1. EditableTextCell - string value, text input
2. EditableCurrencyCell - string value, text input with currency formatting
3. EditableDateCell - string value with ISO conversion, date input
4. EditableNumberCell - number value with min/max bounds
5. EditablePercentCell - string value with percent formatting
6. EditableSelectCell - different pattern (no editValue string) - keep separate

Create a new hook that encapsulates the common editing state pattern:

```typescript
'use client'

import { useCallback, useState } from 'react'

interface UseEditableCellOptions<T> {
  value: T
  onSave: (value: T) => Promise<unknown>
  /** Convert stored value to string for editing */
  formatForEdit?: (value: T) => string
  /** Convert edited string back to stored type */
  parseFromEdit?: (value: string) => T
}

interface UseEditableCellReturn {
  editing: boolean
  editValue: string
  saving: boolean
  startEditing: () => void
  cancelEditing: () => void
  handleChange: (value: string) => void
  handleSave: () => Promise<void>
  handleKeyDown: (e: React.KeyboardEvent) => void
}
```

**Implementation requirements:**
- `startEditing`: Sets editValue from value (using formatForEdit if provided), sets editing=true
- `cancelEditing`: Sets editing=false
- `handleChange`: Updates editValue
- `handleSave`: Checks if value changed (early return if not), sets saving=true, calls onSave with parseFromEdit result, sets editing=false, catches errors with console.error, finally sets saving=false
- `handleKeyDown`: Enter triggers save, Escape cancels

**Default behaviors:**
- `formatForEdit`: Default to `String(value ?? '')`
- `parseFromEdit`: Default to identity (return editValue as T) - caller provides type-specific parsing

Do NOT include useCallback or useMemo unless specifically needed - keep it simple. React 19 optimizes these automatically.
