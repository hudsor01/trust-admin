# Plan 10-07: Form Migration - ResourceDialog Pages

**Migrate 4 ResourceDialog pages from manual form state to TanStack Form Field components**

## Context

**Current State:**
- Contacts.tsx and Vehicles.tsx already use TanStack Form (Plan 10-03)
- 4 pages use ResourceDialog with manual form state: Accounting, Accounts, Liabilities, Properties
- useResourceForm hook already returns `formInstance` from TanStack Form
- Form wrapper components already exist (FormField, FormSelectField, FormTextareaField)

**Problem:**
These pages use the old pattern:
```typescript
<Input
  value={entryForm.accountingDate}
  onChange={(e) => setEntryForm({ ...entryForm, accountingDate: e.target.value })}
/>
```

**Target Pattern:**
```typescript
<formInstance.Field name="accountingDate">
  {(field) => (
    <FormField
      label="Date"
      error={field.state.meta.errors?.[0]}
    >
      <Input
        type="date"
        value={field.state.value}
        onBlur={field.handleBlur}
        onChange={(e) => field.handleChange(e.target.value)}
      />
    </FormField>
  )}
</formInstance.Field>
```

## Dependencies

**Requires:**
- Plan 10-02: Form wrapper components (FormField, FormSelectField, FormTextareaField)
- Plan 10-03: TanStack Form integration pattern established

**Provides:**
- Accounting.tsx using TanStack Form Field components
- Accounts.tsx using TanStack Form Field components
- Liabilities.tsx using TanStack Form Field components
- Properties.tsx using TanStack Form Field components
- Field-level validation with onBlur
- Improved error display

## Risks & Mitigations

**Risk:** Breaking existing form functionality during migration
- **Mitigation:** Migrate one page at a time, test thoroughly before moving to next

**Risk:** Conditional fields (like incomeType vs expenseType) not working with Field
- **Mitigation:** Use field.state.value to conditionally render fields

**Risk:** Switch components not compatible with field.handleChange
- **Mitigation:** Use field.handleChange(boolean) for Switch onCheckedChange

## Notes
