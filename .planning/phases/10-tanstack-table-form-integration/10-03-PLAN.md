}

2. **Use TanStack Form hook**:
```typescript
const form = useForm({
  defaultValues: initialData,
  validatorAdapter: zodValidator(),
  validators: schema ? {
    onBlur: schema,  // Validate on blur (balanced approach from research)
  } : undefined,
  onSubmit: async ({ value }) => {
    setIsSubmitting(true)
    try {
      await onSubmit(value)
      close()
    } catch (error) {
      throw error
    } finally {
      setIsSubmitting(false)
    }
  },
})
```
