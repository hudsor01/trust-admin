# Plan 02-01: Enable Vercel Preview Branching

## Objective

Configure Neon-Vercel integration to automatically create database branches for each Vercel preview deployment.

## Context

Currently: PRs deploy to Vercel but share the production database.
Goal: Each PR gets its own isolated database branch with production data copy.

## Tasks

### 1. Configure Neon-Vercel Integration
- [ ] Go to Neon Console → Project Settings → Integrations
- [ ] Connect to Vercel (Neon-managed integration for existing account)
- [ ] Enable "Create a branch for every preview deployment"
- [ ] Set branch TTL for auto-cleanup (e.g., 7 days)

### 2. Update Environment Variables
- [ ] Vercel will auto-inject `DATABASE_URL` for preview branches
- [ ] Ensure `NEON_AUTH_BASE_URL` works with preview branches
- [ ] Verify all required env vars are set in Vercel project

### 3. Test Preview Deployment
- [ ] Create test PR
- [ ] Verify new Neon branch created
- [ ] Verify preview deployment uses branch database
- [ ] Verify branch cleanup after merge

## Success Criteria

- [ ] Preview deployments get isolated database branches
- [ ] Schema migrations work on preview branches
- [ ] Branches auto-delete when PR closes
- [ ] No manual DATABASE_URL management needed

## Notes

This is primarily Vercel/Neon console configuration, not code changes.
