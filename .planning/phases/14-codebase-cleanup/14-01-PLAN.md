<task type="auto">

<action>

1. REMOVE the existing `X-Frame-Options` entry from securityHeaders (it will be superseded by CSP)

2. ADD this entry to securityHeaders array:
```typescript
{
    key: 'Content-Security-Policy',
    value: [
        "default-src 'self'",
        "script-src 'self' 'unsafe-inline' 'unsafe-eval'",
        "style-src 'self' 'unsafe-inline'",
        "img-src 'self' data: blob: https://utfs.io https://*.ufs.sh",
        "font-src 'self'",
        "connect-src 'self' https://*.ingest.sentry.io https://*.neon.tech wss://*.neon.tech",
        "frame-ancestors 'none'",
        "object-src 'none'",
        "base-uri 'self'",
        "form-action 'self'",
    ].join('; '),
},
```

Then run: bun run typecheck
</action>
