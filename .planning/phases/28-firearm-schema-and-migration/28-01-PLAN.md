## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-28-02 | Tampering | `document` / `valuation` single-owner CHECK constraints | mitigate | Both CHECK expressions are extended to count `firearmId` (9-FK and 7-FK sums, `= 1`) so a row with two non-null asset FKs is still rejected |
| T-28-03 | Tampering | `insertFirearmSchema` input validation (V5) | mitigate | Serial-number regex `^[A-Za-z0-9-]+$` + 50-char max; `positiveNumberValidation` on `dodValue`/`acquisitionCost`; NFA-conditional `.refine()` blocks `isNfa=true` with null `nfaClass` |
| T-28-04 | Elevation of Privilege | `firearm` table row visibility (V4 Access Control) | mitigate | Table chains `.enableRLS()` and declares 4 `crud-authenticated-policy-*` policies; the select policy gates on `app.is_admin()` — a missing `.enableRLS()` would leave the table unprotected (verified by acceptance criteria) |
| T-28-SC | Tampering | npm package installs | accept | No package-manager installs in this phase — all tooling (drizzle-orm, drizzle-zod, zod) pre-exists; no supply-chain surface |
</threat_model>
