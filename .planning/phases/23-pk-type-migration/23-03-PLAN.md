<task type="auto">
  <name>Task 2: Update seed script for numeric IDs</name>
  <files>db/seed-hudson-trust.ts</files>
  <action>
Update the seed script to work with BIGINT IDENTITY columns.

**Key principle:** Don't specify IDs, use `.returning()` to get them for FK references.

**Changes needed:**

1. **Remove generateId import:**
```typescript
// REMOVE:
import { generateId } from './queries'
```

2. **Update entity creation:**
```typescript
// FROM:
const trustId = generateId()
await db.insert(entity).values({
    id: trustId,
    name: 'The Hudson Living Trust',
    ...
})

// TO:
const [trust] = await db.insert(entity).values({
    // NO id field
    name: 'The Hudson Living Trust',
    ...
}).returning({ id: entity.id })
const trustId = trust.id  // Now it's a number
```

3. **Update all resource creations to use .returning() when ID needed:**

For beneficiaries (IDs needed for FK references later):
```typescript
// Insert all beneficiaries and collect their IDs
const beneficiaryInserts = await db.insert(beneficiary).values([
    { entityId: trustId, name: 'Richard Hudson Jr', ... },
    { entityId: trustId, name: 'Ashley Hudson', ... },
    // ... all beneficiaries
]).returning({ id: beneficiary.id, name: beneficiary.name })

// Now you have: [{ id: 1, name: 'Richard Hudson Jr' }, { id: 2, name: 'Ashley Hudson' }, ...]
// Use these for FK references
const richardJrId = beneficiaryInserts.find(b => b.name === 'Richard Hudson Jr')?.id
```

4. **For resources that don't need ID references:**
Simply remove `id` from values and don't use `.returning()`:
```typescript
await db.insert(homestead).values({
    // NO id
    entityId: trustId,
    streetAddress: '123 Main St',
    ...
})
```

5. **Update trustee and other linked records:**
Use the same pattern - insert without ID, use .returning() if ID needed for subsequent inserts.

**Batch insert consideration:**
If batch inserting and needing IDs back:
```typescript
const inserted = await db.insert(someTable)
    .values(arrayOfValues)  // No id in each value object
    .returning()
// inserted is array with generated IDs
```

**Note:** The seed script has many interconnected inserts. Take care to:
- Process in dependency order (entity → beneficiaries → distributions)
- Use .returning() for any record whose ID is referenced by later inserts
- Remove all explicit `id: generateId()` patterns
