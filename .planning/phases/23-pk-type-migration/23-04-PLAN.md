Run full verification suite and fix any remaining type issues.

**Verification steps:**

1. **TypeScript typecheck:**
```bash
bun run typecheck
```

Fix any type errors. Common issues:
- Frontend components expecting `id: string` but getting `id: number`
- URL params needing coercion
- Function parameters typed as string instead of number

2. **Build verification:**
```bash
bun run build
```

Fix any build errors (usually same as typecheck issues).

3. **Test suite:**
```bash
bun test
```

Fix any failing tests:
- Update test fixtures that use string IDs
- Update mock data with numeric IDs
- Fix any ID comparison assertions

4. **Manual smoke test (optional but recommended):**
```bash
bun run dev
```

Test in browser:
- Create a new resource (ID should be auto-generated number)
- Edit an existing resource
- Delete a resource
- Check that entity selector works
- Verify HEMS workflow

**Common fixes needed:**

**Frontend ID handling:**
```typescript
// If URL contains ID as string, coerce to number:
const id = Number(params.id)

// Or use parseInt with validation:
const id = parseInt(params.id, 10)
if (isNaN(id)) throw new Error('Invalid ID')
```

**Component props:**
```typescript
// Update interfaces from:
interface Props { entityId: string }
// To:
interface Props { entityId: number }
```

**useEntityFilter hook (nuqs):**
If the hook stores entity ID in URL, may need to update from string to number parser:
```typescript
// Check src/hooks/use-entity-filter.ts
// May need: parseAsInteger instead of parseAsString
```

5. **Activity log verification:**
After making test changes, check that activity log records properly with numeric IDs.
