Output: Updated schema.ts with BIGINT IDENTITY PKs and matching FK types, updated helpers.ts, updated Better Auth config.

**Pre-production context:** No data migration concerns. Clean cutover with `drizzle-kit push --force`.

**Better Auth consideration:** Better Auth manages user/session/account/verification tables. The `user.beneficiaryId` FK references `beneficiary.id`, so this must also become bigint. Configure `generateId: false` for database-side ID generation on Better Auth tables.

**Key patterns from research:**
- Use `bigint({ mode: 'number' }).primaryKey().generatedAlwaysAsIdentity()`
- All FK columns must match PK type: `bigint({ mode: 'number' })`
- Remove all `$defaultFn(generateId)` patterns
- Better Auth config: `advanced.database.generateId: false`
</context>

<task type="auto">
  <name>Task 2: Update all FK columns to bigint type</name>
  <files>db/schema.ts</files>
  <action>
Update all foreign key columns to match the new BIGINT type. FK columns that reference application tables must change from `text()` to `bigint({ mode: 'number' })`.

**FK columns to update (~100 total across 28 tables):**

Common FK patterns:
- `entityId: t.text().notNull()` → `entityId: bigint({ mode: 'number' }).notNull()`
- `beneficiaryId: t.text().notNull()` → `beneficiaryId: bigint({ mode: 'number' }).notNull()`
- Nullable FKs: `homesteadId: t.text()` → `homesteadId: bigint({ mode: 'number' })`

**Search for these patterns and update:**
1. `entityId` FK in all tables
2. `beneficiaryId` FK in distribution, hemsRequest, withdrawalRecord, specificBequest
3. `liabilityId` FK in liabilityPayment
4. `trusteeId` FK in trusteeFeeSchedule
5. `vehicleId`, `homesteadId`, `rentalPropertyId` FKs in liability, valuation, document, transaction
6. `bankAccountId`, `investmentAccountId` FKs in various tables
7. `feeScheduleId` FK in trusteeFeeEntry
8. `hemsRequestId`, `distributionId` FKs
9. All other inter-table references

**Special case - Better Auth user.beneficiaryId:**
This is defined in auth.ts additionalFields, but the column is in schema.ts. Update the column type in the user table definition:
```typescript
beneficiaryId: bigint({ mode: 'number' }, { name: 'beneficiary_id' }),
```

**DO NOT change** references between Better Auth tables (userId in session/account) - those remain TEXT as Better Auth manages them.
  </action>
  <verify>grep -E "entityId.*text\(\)|beneficiaryId.*text\(\)" db/schema.ts returns no results (all converted)</verify>

  // ... existing config

**In db/helpers.ts:**
