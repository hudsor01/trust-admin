**Constraining decisions:**
- Phase 25: Auto-calculation happens on backend in recordLiabilityPayment() - frontend preview is for UX only
- Phase 25-03: Allocation class moved to payment level, not liability level
- Interest rate stored as percentage in DB (e.g., "6.5"), must divide by 100 for calculations

**Key pitfalls from research:**
- Interest rate format mismatch: DB stores "6.5", calculations need "0.065"
- Null/undefined fields: currentBalance, interestRate can be null
- Credit cards (revolving credit): Don't show payoff date projections
