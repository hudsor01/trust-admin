  <name>Task 1: Create userManagement tRPC router with provisioning mutations</name>
  <files>src/server/trpc/routers/userManagement.ts</files>
  <action>
Create a new tRPC router with three procedures:

**1. `createBeneficiaryUser` (adminProcedure, mutation)**
Input: `{ beneficiaryId: z.number(), email: z.string().email(), tempPassword: z.string().min(8) }`

Steps:
a. Query beneficiary by ID — throw NOT_FOUND if missing
b. Check userProfile table for existing record with this beneficiaryId — throw CONFLICT if exists ("Beneficiary already has a portal account")
c. Also check if email is already taken by another Neon Auth user — call authServer.admin.listUsers({ searchValue: email, searchField: 'email' }) and check results. If email exists, throw CONFLICT ("Email already in use")
d. Call `authServer.admin.createUser({ email, password: tempPassword, name: ben.firstName + ' ' + ben.lastName, role: 'user' })` — Neon Auth native role is always "user"
e. If createUser error, throw BAD_REQUEST with error message
f. Insert userProfile: `{ userId: newUser.id, role: 'beneficiary', beneficiaryId }`
g. Call createActivityLog with tableName='user_profile', action='CREATE', changedBy=ctx.user.id
h. Return `{ userId: newUser.id, email }` — do NOT return the password

Import authServer from `@/lib/auth/server` (or `@/lib/auth` depending on re-export).

**2. `listProvisionedUsers` (adminProcedure, query)**
No input required.

Steps:
a. Left join userProfile with beneficiary to get linked beneficiary info
b. Select: userProfile.userId, userProfile.role, userProfile.beneficiaryId, userProfile.createdAt, beneficiary.firstName, beneficiary.lastName, beneficiary.email (as beneficiaryEmail)
c. Return the array sorted by createdAt desc
d. Note: We don't query neon_auth.user directly — we can't. The userProfile table is our source of truth for app-level users.

**3. `resetUserPassword` (adminProcedure, mutation)**
Input: `{ userId: z.string(), newPassword: z.string().min(8) }`

Steps:
a. Verify userProfile exists for this userId — throw NOT_FOUND if missing
b. Call `authServer.admin.setUserPassword({ userId, newPassword })` — this requires admin session (auto-forwarded via cookies in route handler context)
c. If error, throw BAD_REQUEST
d. Call createActivityLog with tableName='user_profile', action='UPDATE', changedBy=ctx.user.id, newValues: { passwordReset: true }
e. Return `{ success: true }`

Follow the exact pattern from `src/server/trpc/routers/beneficiary.ts` — import createTRPCRouter, adminProcedure, TRPCError from the right places. Use `eq` from drizzle-orm for where clauses.
