# Phase 24 Plan 01: Table Naming Convention Migration

## Objective

Migrate 27 application tables from PascalCase to snake_case naming convention per PostgreSQL best practices. Update schema.ts to reflect new table names and update FK constraint names for consistency.

## Research Reference

See: `24-RESEARCH.md` for full analysis of PostgreSQL identifier handling and Drizzle patterns.

## Scope

**In Scope:**
- 27 application tables: PascalCase → snake_case
- ~50 FK constraint names: Update to snake_case pattern
- schema.ts: Update table name strings
- Verification of all queries working

**Out of Scope:**
- Better Auth tables (account, session, user, verification) - already lowercase
- Custom indexes - already use snake_case (`idx_activity_log_*`)
- Column names - stay as-is (Drizzle handles mapping)

**Objective:** Write explicit SQL to rename all 27 tables.

**Steps:**
1. Create `db/migrations/0001_rename_tables_to_snake_case.sql`

### Task 2: Update schema.ts Table Name Strings

**Objective:** Update all pgTable() first arguments to use snake_case.

**Steps:**
1. Open db/schema.ts
2. For each table, change the name string:
   - `pgTable('ActivityLog', ...)` → `pgTable('activity_log', ...)`
   - `pgTable('BankAccount', ...)` → `pgTable('bank_account', ...)`
   - etc.

**Pattern:**
```typescript
// Before
export const activityLog = pgTable('ActivityLog', ...)

// After
export const activityLog = pgTable('activity_log', ...)
```

**Note:** TypeScript variable names stay camelCase.

**Verification:** grep for PascalCase table names returns only Better Auth tables.

### Task 3: Update FK Constraint Names in schema.ts

**Objective:** Update foreignKey() `name` properties to snake_case pattern.

**Steps:**
1. Find all `foreignKey({...name: '...'})` in schema.ts
2. Change from `TableName_columnName_fkey` to `table_name_column_name_fkey`

**Pattern:**
```typescript
// Before
foreignKey({
  columns: [table.entityId],
  foreignColumns: [entity.id],
  name: 'BankAccount_entityId_fkey',
})

// After
foreignKey({
  columns: [table.entityId],
  foreignColumns: [entity.id],
  name: 'bank_account_entity_id_fkey',
})
```

**Verification:** grep for PascalCase in FK names returns 0 results.
