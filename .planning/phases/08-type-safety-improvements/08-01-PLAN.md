# Phase 8 Plan 01: Create Typed Resource Configuration Interface

**Status**: Not started
**Depends on**: Nothing
**Objective**: Define a generic TypeScript interface for resource configurations that eliminates the need for `as any` casts in the route factory, preserving type safety for CRUD operations while maintaining runtime flexibility.

## Execution Context

@db/crud-factory.ts (lines 1-110) - Current CRUD factory implementation
@index.ts (lines 265-440) - Route factory resources object with 22 `as any` casts
@db/schema.ts - All table definitions

## Context

**Problem**: The route factory resources object casts all CRUD instances to `any` because TypeScript can't infer a common type across heterogeneous table types. This loses compile-time safety:

```typescript
const resources: Record<string, RouteConfig> = {
  "entities": { crud: entityCrud as any, ... },  // ← Type safety lost here
  "beneficiaries": { crud: beneficiaryCrud as any, ... },  // ← And here
  // ... 20 more resources with as any
}
```

**Root cause**: `RouteConfig` interface doesn't use generics, so it can't preserve the specific table types from each CRUD instance.

**Current types**:
- `CrudOperations<TTable, TInsert, TSelect>` - Generic CRUD interface
- `RouteConfig` - Non-generic route configuration interface
- Each CRUD instance (e.g., `entityCrud`) has specific types for its table

**Goal**: Create a generic `ResourceConfig<TTable>` interface that:
1. Accepts any Drizzle table type
2. Preserves type safety for CRUD operations
3. Allows heterogeneous resources collection without `as any`
4. Maintains runtime flexibility (optional fields, custom getById)

## Tasks

### Task 1: Define generic ResourceConfig interface

Create `ResourceConfig<TTable>` interface in index.ts that:
- Accepts generic table type parameter
- Uses Drizzle's type inference for Insert/Select types
- Includes all current fields: crud, name, filterParam, insertSchema, updateSchema, references, customGetById
- Makes CRUD operations type-safe without casting

**Target location**: index.ts, before resources object (around line 260)

**Implementation pattern**:
```typescript
interface ResourceConfig<TTable extends PgTable> {
  crud: CrudOperations<TTable, InferInsertModel<TTable>, InferSelectModel<TTable>>
  name: string
  filterParam?: string
  insertSchema?: ZodSchema
  updateSchema?: ZodSchema
  references?: ReferenceValidation[]
  customGetById?: (id: string) => Promise<InferSelectModel<TTable> | undefined>
}
```

**Verification**: TypeScript compiles without errors, interface is defined with proper generic constraints.

**Commit**: `feat(08-01): add generic ResourceConfig interface`

### Task 2: Update resources object to use typed configs for 3 test resources

Update 3 diverse resources (entities, liabilities, tasks) to use `ResourceConfig<typeof table>` instead of casting:

Before:
```typescript
const resources: Record<string, RouteConfig> = {
  "entities": {
    crud: entityCrud as any,  // ← Remove this cast
    name: "Entity",
    customGetById: getEntityById,
  },

```

After:
```typescript
const resources: Record<string, ResourceConfig<any>> = {  // Temporary - will fix in Task 3

    customGetById: getEntityById,

}
```
