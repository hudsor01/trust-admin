## Section 5 — Tech Debt Logged

1. **NfaStatusDialog discoverability** — 2 interactions deep (row expand → button visible only if isNfa=true). By D-02 design (CQS separation from FirearmDialog). Track as future UX enhancement if admins report friction.
2. **`beneficiary.create` / `beneficiary.update` accept `sortIndex` input** — Future hardening could tighten the schemas to auto-manage `sortIndex` now that the drag-reorder UI is gone. Out of scope per D-14; tracked in 33-CONTEXT.md deferred ideas.
3. **KpiStrip caps at 5 tiles via explicit conditional** — Any future 6+ tile caller needs an extension to `data.length === 5 ? 'lg:grid-cols-5' : 'lg:grid-cols-4'` or a generalization to `lg:grid-cols-${data.length}`. Tracked in STATE.md.
4. **Sentry DEP0205 suppression flag** — `NODE_OPTIONS='--disable-warning=DEP0205'` on dev/build scripts in package.json. Removable once `@sentry/node-core` ships `module.registerHooks()` migration. Currently `@sentry/node-core@10.53.1` still uses `module.register()`.
5. **Nyquist VALIDATION.md missing on phases 30-33** — Carry-over tech debt from v4.0; not a v5.0 acceptance criterion. Backfill with `/gsd:validate-phase` per phase when prioritized.

## Section 6 — Deferred to Future Milestones

Items explicitly placed Out of Scope in REQUIREMENTS.md or surfaced as Deferred Ideas in phase CONTEXT.md files:

| Item | Rationale |
|------|-----------|
| Beneficiary `sortIndex` auto-management | Drag-reorder UI removed in Phase 33; column + ORDER BY preserved. Schema-tightening (auto-assign on insert via ROW_NUMBER or insertion order) is a future cleanup. |
| ATF Form 5 / eForms e-filing integration | ATF eForms uses a proprietary authenticated API not exposed to third parties — record form numbers and attach approved stamps manually |
| NICS / background-check / prohibited-person verification | NICS is an FFL-only federal system; unauthorized access is a federal offense |
| Ammo inventory, ballistic data, accessories tracking | Not relevant to trust administration — use the notes field or a `personalProperty` line item |
| Gun-trust "responsible persons" schedule / ATF 5320.23 | The Hudson Trust is not a dedicated NFA gun trust — it holds firearms as ordinary estate property |
| Automatic NFA-class inference from barrel length | ATF classification is not algorithmic — surface a hint only; human confirmation required |
| Bulk CSV import for firearms | Manual entry is sufficient for this estate's collection size |
