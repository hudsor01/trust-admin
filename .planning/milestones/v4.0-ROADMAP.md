# Milestone v4.0: Smart Liability Management

**Status:** SHIPPED 2026-01-17
**Phases:** 25-29
**Total Plans:** 7

## Overview

Transform liability tracking from simple balance recording to intelligent loan management with automatic amortization calculations, payment tracking, and payoff projections. Make it easy to enter initial loan terms and have the system handle all calculations automatically.

## Phases

### Phase 25: Loan Terms Schema & Calculation Engine

**Goal**: Add schema fields for loan terms and build backend amortization calculation logic
**Depends on**: v2.0 complete
**Plans**: 3 plans

Plans:
- [x] 25-01: Loan terms schema (4 fields added)
- [x] 25-02: Amortization calculation utilities
- [x] 25-03: Integration into payment workflow

**Details:**
- Schema Additions: loanTermMonths (integer), loanStartDate (date), escrowMonthly (decimal), isRevolvingCredit (boolean)
- Calculation Functions: calculatePaymentSplit, calculateMonthlyPayment, estimatePayoffDate, getCurrentLoanPosition
- Replaced dinero.js with native Intl.NumberFormat - zero dependencies for money math
- Pattern: toCents() → integer math → fromCents() → string storage

### Phase 26: Type-Aware Liability Form

**Goal**: Dynamic form that adapts based on liability type, with smart defaults and real-time calculation feedback
**Depends on**: Phase 25
**Plans**: 1 plan

## Milestone Summary

**Key Decisions:**
- Replaced dinero.js with native Intl.NumberFormat (Rationale: dinero.js v2 abandoned, zero deps better)
- Moved allocation class from liability to payment level (Rationale: Texas Property Code compliance)
- Used useDeferredValue for all real-time calculations (Rationale: Smooth UX without lag)
- 90% threshold for partial payment warning (Rationale: Reasonable tolerance)

**Issues Resolved:**
- dinero.js import failures - replaced with native Intl
- React hooks called after early return - fixed in PaymentPreview
- Pre-existing chart TypeScript errors - fixed during development

**Issues Deferred:**
- None
