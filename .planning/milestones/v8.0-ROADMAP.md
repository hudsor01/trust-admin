# Milestone v8.0: Public Inventory Form

**Status:** ✅ SHIPPED 2026-01-22
**Phases:** 46-48
**Total Plans:** 3

## Overview

Public-facing inventory form with AI-powered photo analysis. Admin queue for review/approval. Enables non-technical users to submit property inventory via photos, with AI-assisted categorization and value estimation.

## Phases

### Phase 46: MLX Vision Integration

**Goal**: AI photo analysis endpoint for inventory items
**Depends on**: Phase 45
**Plans**: 1 plan

Plans:
- [x] 46-01: Local AI inventory analysis with Vercel AI SDK

**Details:**
- Created `/api/inventory/analyze` endpoint
- Integrated Vercel AI SDK with Claude Opus 4.5 (switched from Ollama)
- Support for 1-5 images per item
- Domain-specific system prompt for trust inventory valuation
- Category mapping from 17 AI categories → 6 DB enum values

### Phase 47: Public Inventory Form

**Goal**: Public submission form at /forms/inventory
**Depends on**: Phase 46
**Plans**: 1 plan

Plans:
- [x] 47-01: Public inventory form with photo upload

**Details:**
- Created public `/forms/inventory` route (no auth required)
- Photo upload via Uploadthing for persistent storage

## Milestone Summary

**Key Decisions:**
- Switched from Ollama/Qwen3-VL to Claude Opus 4.5 for better accuracy and no local model dependency
- Uploadthing for persistent photo storage (instead of local filesystem)
- Passphrase protection for public form (prevents spam submissions)
- Server Actions for progressive enhancement
- Approval flow creates personalProperty records directly

**Issues Resolved:**
- Sentry HMR error in development (multiple replay instances)
- Image compression for Anthropic API (base64 size limits)
- Magic link authentication flow for Better Auth

**Technical Debt Incurred:**
- None significant
